    Statistical Formulas

    Mean: x̄ = Σx / n

    Add up all the values and divide by how many there are. It is the "average" or centre of the data.

    Variance: σ² = Σ(x − x̄)² / n

    For each value, find how far it is from the mean, square it, then average these. It tells us how spread out the data is.

    Standard Deviation: σ = √Variance

    The square root of variance. It is the typical distance of a value from the mean, in the original units.

    Covariance: Cov(X,Y) = Σ[(X − X̄)(Y − Ȳ)] / n

    Shows whether X and Y move together. Positive means both tend to rise together; negative means one rises as the other falls.

    Pearson Correlation: r = Cov(X,Y) / (σX × σY)

    Covariance rescaled to lie between −1 and +1. Near +1: strong positive line. Near 0: weak or no linear relationship. Near −1: strong negative line. Correlation does not prove causation.

    Simple Linear Regression: ŷ = b₀ + b₁x

    The best-fit straight line through the points, where b₁ = Cov(X,Y) / σX² and b₀ = Ȳ − b₁X̄. We use it to estimate marks for a given number of study hours.

    About Project

    Project Title

    Study Hours vs Academic Performance Analyzer

    Project Description

    A statistical application that analyzes the relationship between students' study hours and academic marks. It uses statistical calculations and graphs to identify the correlation between study time and performance and uses linear regression to estimate expected marks.
